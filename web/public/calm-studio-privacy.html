Calm Studio privacy policy

Updated 28 October 2026 · Personal application operated by Petr Lavrov

Purpose and access

Calm Studio uses the YouTube API to upload the owner's finished videos, organize them in a private Morning Show playlist, and verify their channel, privacy and playlist membership.

The application reads the authorized channel's ID and title, playlist IDs, titles and privacy settings, and the uploaded video's ID, title, description, duration and status. It sends the selected video file, title, description and privacy settings to YouTube.

Google groups uploads and playlist management under a broad YouTube account permission. The uploader uses this permission for the personal video and playlist workflow described above.

Storage and retention

OAuth credentials and refresh tokens are stored in the owner's encrypted Calm Keys store. Local video files and delivery receipts remain on the owner's computers. Receipts contain video and playlist IDs, publication metadata and a file checksum.

Uploaded episodes and the Morning Show playlist are set to private. YouTube stores these uploads under the connected account. Local files, receipts and uploads remain until the owner removes them.

Use and sharing

Google user data is used to provide the owner's video upload and playlist workflow. The uploader does not sell Google user data, share it with advertisers, or use it for advertising or training AI models.

The public information pages contain no sign-in form, tracking script or embedded video player. The website hosting provider processes ordinary web requests to serve them. YouTube's processing is described in the Google Privacy Policy.

Stop access or remove data

The owner can remove Calm Studio's access in Google Account permissions. This prevents future API access. Existing uploads can be removed in YouTube Studio; local credentials, files and receipts can be removed from the owner's computers.

For questions or a request to remove locally retained data, contact petrlavrov@calmmage.com.
